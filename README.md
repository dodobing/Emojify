# Emojify — GIF 이모티콘 생성기 (Slack Emoji Maker)

텍스트를 한 줄씩 입력하면 **순서대로 바뀌는 애니메이션 GIF 이모티콘**을 만들어 줍니다.
Slack 커스텀 이모지 규격(128×128, 128KB 이하, 투명 배경 지원)에 맞춰 출력합니다.

## 특징

- **11개 언어 UI** — 한국어·English·日本語·简体中文·繁體中文·Español·Français·Deutsch·ไทย·हिन्दी·Русский. 접속 시 **브라우저 언어로 자동 표시**되고, 상단 선택기로 즉시 전환(선택은 브라우저에 저장).
- **의존성 0 · CDN 0** — 단일 `index.html`. GIF89a + LZW 인코더를 직접 내장해 브라우저에서만 동작합니다.
- **입력 방식 2가지** — 여러 줄 입력은 줄마다 프레임, **한 줄 입력은 글자마다 프레임**(타이핑처럼 한 글자씩 전환)
- **마지막 빈 프레임** 옵션(기본 ON) — 시퀀스 끝에 글자 없는 프레임을 넣어 깜빡임/쉼 효과
- **8가지 스타일 프리셋** — 파티(무지개)·네온·클래식·다크·캔디·매트릭스·선샤인·투명
- **자유 커스텀** — 폰트(한글 지원), 글자색/배경색, 투명 배경, 무지개 글자, 글로우, 볼드, 속도, 크기(64~160px)
- **자동 텍스트 맞춤** — 긴 텍스트는 자동 줄바꿈 + 폰트 축소로 프레임 안에 맞춥니다.
- **실시간 미리보기** + 생성 후 용량 표시 및 Slack 128KB 초과 경고

## 사용법

1. 프리셋을 하나 고릅니다 (색·폰트·효과가 자동 입력됨).
2. 텍스트를 **한 줄에 한 프레임**씩 입력합니다.
3. 필요하면 스타일을 조정하고 **GIF 생성하기** → **다운로드**.
4. Slack → 워크스페이스 이름 → 사용자 지정 이모티콘 추가 → 업로드.

## GitHub Pages 배포

1. 이 폴더의 `index.html`을 GitHub 저장소 루트(또는 `/docs`)에 올립니다.
2. 저장소 **Settings → Pages** 에서 Source를 해당 브랜치로 지정.
3. `https://<사용자명>.github.io/<저장소명>/` 으로 바로 접속해 동작합니다.

> 한글 표시용 Google Fonts(Black Han Sans, Jua, Do Hyeon, Gaegu)만 외부에서 불러옵니다.
> 폰트 로딩이 막힌 환경에서도 시스템 기본 폰트로 정상 동작합니다.

## 로컬에서 열기

브라우저로 `index.html`을 직접 열거나:

```bash
python -m http.server 8771 --directory .
# http://localhost:8771
```
